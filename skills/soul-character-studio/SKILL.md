# Higgsfield Soul Character Studio

## Reference Photo Standards

| Tier | Count | Use |
|------|-------|-----|
| Minimal | 5–8 | Testing |
| Standard | 10–15 | Ongoing content |
| Premium | 20–30 | AI influencer, series |

Required diversity: angle coverage (front, 3/4 left, 3/4 right) + expression range (neutral, smile, serious) + lighting variety (daylight, indoor soft, directional)

Technical: min 1024×1024px, face sharp and 40%+ of frame, no sunglasses, no heavy filters/retouching, no blur.

## Character Bible Template

Character name / Soul training ID / Physical anchor (2–3 sentences, defining features) / Default aesthetic / Signature wardrobe / Default lighting / Color palette / Tone-mood / Forbidden elements

## 5 Scene Prompt Templates

**Editorial** — 85mm portrait compression, simple background, soft editorial lighting. Negative: background clutter, inconsistent skin tone.

**Lifestyle/Product** — 35–50mm, describe action not just look, natural ambient light, casual body language.

**UGC/Social** — selfie-style, iPhone aesthetic, natural window light, casual wardrobe version. Negative: studio lighting, posed.

**Outdoor/Cinematic** — match character color palette to environment, slow tracking or static, atmospheric element.

**Studio** — clean background, three-point or single soft key light, 85mm shallow DOF. Most stable for character consistency.

## Style Lock Rules

- Always carry 2–5 word visual anchor phrase in every prompt
- Lock lighting direction — more important than clothing consistency
- Test across all 5 scene types before launching campaign
- If drift occurs: regenerate in Studio scene first, then others
