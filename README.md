# Claude + Higgsfield — Levois Content Production

Production de contenu immobilier automatisé pour levois.fr

## Structure

```
/scripts/         — Scripts SÉCLA par épisode
/broll-prompts/   — Prompts B-roll Kling 3.0
/skills/          — Skills Higgsfield installés
/workflow/        — Briefings de production
/calendrier/      — Planning de publication
```

## Stack technique
- **Avatar** : HeyGen (clone Mouaad)
- **Voix** : ElevenLabs (clone pro)
- **B-rolls** : Higgsfield Kling 3.0
- **Montage** : HyperFrames → MP4 final
- **Pilotage** : Claude (ce repo)

## Méthode éditoriale
Scripts SÉCLA : Situation → Écart de perception → Compréhension → Lecture concrète → Action utile

Série 1 : "Pourquoi votre bien attire sans déclencher de décision" — 8 thèmes × 4-5 angles = 35+ vidéos
